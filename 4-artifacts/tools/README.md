# Tools

**Integrations your daimon reaches** — what it can *touch in the outside world*: Gmail, LinkedIn, an API, a CLI (often via MCP).

**The trio — so you don't mix them up:**
- **Tool** *(here)* — *what it can reach.* An external integration. → `4-artifacts/tools/`
- **Command** — *how you call it.* A verb you invoke. → `3-actions/commands/`
- **Skill** — *what it knows how to do.* A capability it applies. → `4-artifacts/skills/`

Add as you grow.
