# Commands

**Verbs you invoke** — how you *tell* your daimon to act. You type them; they trigger a workflow.
Examples: `@summon` (bring your daimon online), `pandaimon play` (compile your surface).

**The trio — so you don't mix them up:**
- **Command** *(here)* — *how you call it.* A verb you invoke. → `3-actions/commands/`
- **Skill** — *what it knows how to do.* A capability it applies. → `4-artifacts/skills/`
- **Tool** — *what it can reach.* An external integration. → `4-artifacts/tools/`

You start with `summon` + `play`; add more verbs as you grow.
